# Sistema de Gestión de Biblioteca Digital

## Descripción General
Este proyecto implementa un sistema de gestión para una biblioteca digital.  
Permite administrar libros, usuarios registrados, préstamos activos y un historial de acciones.  
El desarrollo cumple estrictamente con los requisitos solicitados en la actividad, utilizando tuplas, listas, diccionarios y conjuntos como estructuras principales.
