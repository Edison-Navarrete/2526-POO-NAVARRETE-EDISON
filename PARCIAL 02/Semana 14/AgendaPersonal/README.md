# Agenda Personal (Tkinter)

Aplicación GUI en Python (Tkinter) que permite agregar, ver y eliminar eventos con **Fecha**, **Hora** (24 h) y **Descripción**. Incluye **DatePicker** propio, **TreeView**, validación de entradas, confirmación al eliminar y organización con **Frames**.

## Requisitos
- Python 3.10–3.13
- Tkinter disponible en el intérprete (verificación):
  ```bash
  python -c "import tkinter; print('OK Tk', tkinter.TkVersion)"
